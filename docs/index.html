Does this sound familiar?

  • Your Chrome Saved tab groups bar keeps growing — the same names appear twice, three times, more.
  • Tab groups multiply on every restart and never go away.
  • It's worse with Tab Session Manager (TSM) restoring your session.
  • Chrome gets slower and slower to start the more they pile up.
  • Turning off “Save tab groups” loses your group names; deleting them by hand just brings them back.

If any of that rings a bell — this fixes it.

Why no extension can fix this

Chrome stores saved tab groups in an internal database (LevelDB) that extensions can't reach — there's no API for saved tab groups. Some session managers rebuild your groups on every startup but Chrome never removes the old copies, so they accumulate without bound. This tool cleans that storage directly, while Chrome is closed, then lets your session manager rebuild exactly one clean set.

How to use it

  1. Download the latest release and unzip it.
  2. Double-click the tool that fits you (see the table above).
  3. It closes Chrome, cleans up, and reopens it — done. One clean group row.

Prefer source? It's pure Python (Windows/macOS/Linux) — see the README.

Safe by design

🔒 Backs up first

A full backup is saved before every cleanup. Fully reversible.

🎯 Surgical

Only touches saved-tab-group data — bookmarks & settings are left alone.
